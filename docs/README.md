# MOBI Documentation

This directory is the production knowledge base for the repo.

- `architecture/README.md` maps the implemented source layout and dependency rules.
- `architecture/history/` preserves earlier plans, inventories and retired scaffolding.
- `product/` holds product and design-system documentation that is not runtime source.
- `security/` holds audit reports, security hardening notes, and release-risk records.
- `release/` documents production release gates and rollback expectations.
- `testing/` documents test strategy and required verification commands.
- `operations/` documents operational ownership, monitoring, and incident response.

Root-level `README.md`, `CRITICAL_RULES.md`, and `design.md` remain at the repo root because they are primary entry points referenced by humans and tooling.
