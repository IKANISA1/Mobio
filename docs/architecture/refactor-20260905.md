The canonical repository is now `/Volumes/PRO-G40/mobio`, on `main` at

## Result

Application startup, routing and shell have one home in `lib/app/`. Feature code
now follows application/data/domain/presentation boundaries; core infrastructure
is grouped by responsibility. All 42 relocated service implementations preserve
their method bodies. Fifteen provider modules replace the shared service container.

Eighteen redundant model/theme wrappers and the BioPay screen barrel are removed.
QR/NFC payload helpers are shared through a pure Dart domain module. The app uses
the existing shared packages directly. Thirty-three files of placeholder
scaffolding are consolidated into architecture history.

Misplaced parent-level configuration and evidence are consolidated. Native bridge
QA history shares the main release-evidence directory. Generated failures, loose
logs and old caches are preserved in the Git-ignored `output/` directory. The 232 pre-existing
local PNG changes were individually copied and verified with SHA-256 hashes.

Flutter workflows are aligned to 3.44.3. Shared SDK/configuration helpers remove
duplicated build logic; bootstrap now generates models for a clean checkout.
Architecture checks prevent dependency inversions, dangling imports, placeholder
packages, tracked generated output and CI SDK drift. The PWA packaging script is
also compatible with the workstation's Python 3.9.

See [the architecture map](README.md), [source moves](source-moves.json), and
[the change history](structure_refactor_changelog.md).
