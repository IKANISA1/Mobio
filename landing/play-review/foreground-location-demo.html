Mobio foreground location demo

This page is provided for Google Play review of Mobio package rw.mobi.app. It documents the foreground service location use case for driver live sharing.

Declaration summary

Permission
FOREGROUND_SERVICE_LOCATION
Task
User-initiated driver location sharing.
Starts
Only after a signed-in driver explicitly goes online.
Stops
When the driver goes offline or cancels live sharing.
Notification
Mobio live location.

Review access

  • Select Passenger or Driver on the login screen.
  • Use phone number +250788767816.
  • Use OTP 123456. No WhatsApp message is required.
  • For driver review, switch to Driver and use the same phone and OTP.

User disclosure

Mobio tells drivers: "Allow background location so Mobio can share your driver location with passengers while you are online, even if you switch apps. Turn off sharing anytime by going offline."
